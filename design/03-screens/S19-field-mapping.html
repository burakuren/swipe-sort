S19 Field mapping

Step 3 of the import: detected fields with sample values from the real records; rename, set the type, hide, choose the title field, handle several values. Spec: S19-field-mapping.md. Shared stepper and app bar: components › Navigation.

Field mapping by source

One layout for every source. Each row: detected field name, sample values from real records, type, show on cards, rename. The title field is chosen at the top. Steps without mapping (photos, manual entry) never show this screen.

Editing a field

Rename inline. Type, title field and several values open bottom sheets (Select). Fields SwipeSort hides on its own sit in a collapsed group at the end.

Validation and limits

Every card needs a title. Errors appear after Continue, at the field, with icon and text. Sources with more than 50 columns import the first 50 until the user chooses.

Loading

Fields and sample values are read from the selected items. Large files show a skeleton for up to a few seconds.

Accessibility

At 200% text the row stacks: name, samples (wrapping), type and several-values selects, then a labeled switch row. The type icon box is dropped to give the text room.

iOS and web

iOS: 44 pt bar with a back chevron (edge swipe goes back a step) and close at the right; the type select is a pull-down menu; other choices open page sheets. Web: same as Android; selects open as popovers on desktop.
