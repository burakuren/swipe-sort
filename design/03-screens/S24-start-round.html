Choose items and card order

A full-screen modal from S09 (Start new round) or S27 (Re-sort Maybe, Start a new round). Items: All, Maybe pile, Accepted items, Custom selection, each with its count. Card order: Original, Shuffled, Sorted by a field. The summary above Start round always states the round size.

Custom selection

Filter by any field (field, condition, value chips) with a live count, or pick items by hand. Pseudo-fields My decision (and List status on shared lists) are filterable too.

Unavailable options and loading

Options with nothing in them stay visible but disabled, with the reason in place of the description. Counts load from the working copy; while counting, Start round waits.

Shared lists

Rounds on shared lists are started by the Owner and apply to every member (DM-15). Piles use final decisions. Collaborators and the Decision Maker can propose a round and ask the Owner.

After Start round

Start round replaces this modal with S25 at the first card of the new round. The snackbar names the action.

Accessibility

At 200% text the counts move under each option and the descriptions wrap; the screen scrolls and the summary with Start round stays pinned.

iOS and web

iOS presents the modal as a page sheet with Cancel in the navigation bar, trailing checkmarks instead of radio buttons and a pull-down menu for the sort field. Web uses the Android layout; on desktop the Select opens as a popover.
