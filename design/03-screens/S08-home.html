S08 Home (Lists)

The Lists tab: every list with its progress, resume sorting in one tap, start a new list. First run offers a sample list; without an account a quiet indicator says lists live on this phone only. Spec: S08-home.md.

First run and sample

No lists yet: one sentence, Import a list (main action) and Try a sample list. The sample is a copy of the 20 Desk setup products, so the first impression is neutral, not wedding-specific.

Lists

Lists are ordered by latest activity. Each ListRow shows the name, a status line and progress: a bar with "decided / total" for a round in progress, decision counts for a finished round. Rounds in progress have a Resume button that opens sorting directly. Shared lists show open conflicts. Signed in, a list kept on this phone only carries a muted "On this phone only" label in its status line (A-137); backed-up lists show nothing. The extended FAB starts a new list (Android); Archived lists sit at the end.

Search

The search button opens a search field over the large title. Results filter live by any word in the list name (case- and accent-insensitive, so "izmir" finds "İzmir"), active lists first, archived lists in their own group.

States

Lists are stored on the device first, so Home opens instantly from local data. The skeleton only shows on a cold start of a large account. Offline, everything stays usable; changes sync later with a quiet notice under the title.

Accessibility

At 200% font size names wrap to 2 lines, meta wraps, the progress fraction moves under the bar and the FAB keeps its label. Rows grow; nothing is cut sideways.

iOS and web

iOS: large title with a search field below it, "+" in the navigation bar instead of a FAB, inset grouped rows, standard tab bar. Web: same layout as Android; without an account the indicator says browsers can clear lists that aren't opened for a while (D-08). Desktop shows the phone column centered; a list kept on Deniz's phone only (Frontend hiring, Q4) is not in the browser.
