S09 List overview

One list: where sorting stands, the next action, and everything you can do with the list. Solo lists show my progress (my decisions are final). Shared lists add list progress (Agreed, Pending, Conflict), the conflict rule, members and activity, and change by role. Spec: S09-list-overview.md.

Solo lists

Solo rule (DM-01): only you sort the list, so your decision is the final decision. The progress card holds the one main action: Continue sorting, Start sorting, or Re-sort Maybe after a finished round.

Shared lists

Every member decides every item (DM-02). My progress is mine; list status is everyone's (DM-14). What changes by role: the Owner starts rounds and sets the conflict rule; the Decision Maker resolves conflicts; Collaborators sort, see conflicts and can leave.

Backup (signed in)

A signed-in Owner of a solo list chooses per list whether it is backed up (A-132): the Backup group under Sources holds one switch. On: the list is in the account. Off: it stays on this phone only; Home and the header say so with a muted label (A-137). Turning it on needs no confirmation; turning it off asks first (S10). Shared lists are always backed up, so the Owner sees the switch disabled with the reason. Not shown without an account, on the sample, to members who don't own the list, or on archived lists.

Archived and states

Archived lists open read-only with Restore as the main action. Loading shows a skeleton only when the list isn't on the device yet (opened from a link). Offline, sorting works; inviting needs a connection.

Accessibility

Large text: the title wraps, counts stack, buttons grow, rows keep their full labels.

iOS and web

iOS: back chevron with "Lists", Share and a "…" menu (opens an action sheet), inset grouped rows, edge-swipe back. Web: same as Android; a list that is only in this browser says "On this browser only" and that browsers can clear lists that aren't opened for a while (D-08). Desktop: the phone column, centered.
