S31 Invite

Sender side of sharing a list: choose the role, then copy or share the invite link. A full-height sheet over the list overview (S09) or the members screen (S34). Spec: S31-invite.md. Prototype flow 3 starts at S31-default.

Inviting (Owner)

First invite for Wedding guests: nobody has joined yet, Deniz is Owner and, by default, Decision Maker (A-26). Collaborator is preselected; the link always reflects the selected role.

Pending invites

Invites are links, so SwipeSort does not list people who opened a link but did not join (they are anonymous until they join). "Pending invites" are the active links: each member has their own link, so the join page can say who invited you. The Owner sees every active link and can turn off anyone's.

Reset link

Resetting revokes the current link (anyone holding it can no longer join) and creates a new one. Members who already joined are not affected. The same dialog pattern is listed in S40.

States

Creating the link, offline, errors, an expired link and a signed-out session.

Roles

Collaborators can invite, but only as Collaborator. The Decision Maker choice is Owner-only.

Accessibility

Large text: descriptions wrap, the link wraps instead of truncating, actions stay pinned at the bottom.

iOS and web

iOS: a page sheet with grabber and Done, roles as a checkmark list, the iOS share icon. Web: Copy link always; Share… only where the browser supports the Web Share API (mobile browsers); desktop shows Copy link only.
