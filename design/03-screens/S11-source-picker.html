S11 Source picker

Step 1 of every import. Each tile is one Source definition; a new source is one more tile that reuses the same steps (Select items, Map fields, Review duplicates, Finish). Spec: S11-source-picker.md. Shared import chrome (modal app bar, ImportStepper, bottom actions) matches S16–S21.

Source picker

Android reference. Tapping a tile opens that source's Select items step. Contacts: Android 16 and lower first show the pre-permission explainer (S12) unless access was already granted; Android 17 and later and iOS open the contact picker intro (S13), which needs no permission. Five sources: the last tile spans both columns.

Web

Contacts import is unavailable in browsers: the tile stays visible with its reason and opens a sheet with “Get the app” and a CSV alternative.

iOS

The import opens as a page sheet: close top-left, centered title. Swipe-down dismisses only while nothing is selected yet (later steps ask first). Contacts opens the contact picker intro (no permission on iOS).
