S17 Manual entry

A new list typed in by hand: define the fields first, then add items one after another. Field mapping and duplicate review are skipped. Spec: S17-manual-entry.md.

Set up fields

Manual entry has no source to map, so the user defines fields first. Name is the title and is always text; other fields can be added, retyped, renamed or removed.

Add items

Items are added one at a time in a sheet. “Add another” saves and clears the form for fast entry; “Add item” saves and closes. Each added item can be edited or deleted (with undo).

Accessibility

At 200% text item titles wrap instead of truncating, and edit and delete become labeled buttons under each item.

iOS

iOS: the item form is a page sheet with Cancel and Add in its own bar (Add = save and close); “Add another” sits under the form. The bar shows a back chevron to Set up fields. Web is the same as Android; the Photo field opens the browser's file picker.
