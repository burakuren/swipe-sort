S15 Google Sheets: choose a spreadsheet and its tabs

Select items for the Google Sheets source (D-17): choose one spreadsheet in Google's file picker (Google's UI, not drawn), choose one or more tabs, preview, then map fields. SwipeSort uses only the drive.file scope: it can open only the files the person chooses, never lists or searches their Google Drive. Spec: S15-google-sheets.md. Shared import chrome (modal app bar, ImportStepper, bottom actions) matches S16–S21.

Choose a spreadsheet

Google's file picker replaces an in-app list of spreadsheets. First time: an explainer, then Google asks for an account and opens the picker. Later: the account is remembered and the picker opens straight away. Cancelling the picker comes back here with nothing changed. No SwipeSort account is needed.

Choose tabs and preview

One tab, or several with the same columns combined into one list. Combined tabs add a Tab field so items keep their origin. Empty tabs are listed but can't be selected.

Errors and offline

Picked file isn't a Google Sheets file, Google connection failure (SRC-23), access removed in the Google account, access blocked by an organization, and no connection. Every state keeps a way to another source.

Web and iOS

Web: Google's JavaScript picker opens over the page after a short Google sign-in window (popup on desktop, redirect on mobile browsers). iOS: the same flow as Android, through the system browser (to be verified when iOS work starts, D-17).
