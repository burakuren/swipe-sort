S13 Contacts import

Select items for the Contacts source: search and multi-select contacts from the address book (96 contacts on Deniz's phone: the 88 sample contacts plus 8 service numbers). Spec: S13-contacts-import.md. Shared import chrome (modal app bar, ImportStepper, bottom actions) matches S16–S21.

Select contacts

Everything starts selected: sorting is where decisions happen, so this step only removes contacts that clearly don't belong, like services and shops. Selection survives searching and clearing the search.

Loading, empty and errors

Contacts are read from the phone, so there is no offline state: the step works the same without a connection.

Very large address books

Thousands of contacts: sticky letter headers and a fast-scroll index on the right edge (Android and iOS). The list is virtualized; search stays the fastest route.

Accessibility

At 200% text, rows grow and names wrap instead of truncating; avatars hide to keep names readable.

iOS

Page sheet with Cancel; round selection marks (iOS convention). iOS 18 can limit contacts to a selection: the list shows only those, with a way to add more.
