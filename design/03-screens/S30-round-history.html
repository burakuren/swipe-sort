Round history

Every round of a list, newest first, with the decision split, counts, what was included, card order, date and sorting time. Tapping a round opens S28 with that round's results; the info button opens the round details. "Latest results" on top is what Results and Export use (A-33).

Shared lists and rounds in progress

On shared lists a round belongs to everyone: the Owner starts it (DM-15), the split shows list status (Agreed, Pending, Conflict) while it runs, and the detail lists each member's results. Sorting time is not shown on shared lists (A-71).

Single round, never sorted and loading

A list with one finished round (here archived, so read-only), a list that was never sorted (the empty state invites the first sort) and the loading skeleton.

iOS and large text

iOS: back chevron with the list name, inset grouped list, the info button is the native detail disclosure (separate tap target from the row). Large text: the split bar stays full width, legend items wrap one per line.
