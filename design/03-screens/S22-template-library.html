S22 Template library

One screen, three modes: manage (Settings › Card templates), pick (the last import step: name the list, choose a card template, start sorting) and change (a list's Card template, applied immediately). Previews render the real SwipeCard from S25 with the list's own items. Spec: S22-template-library.md. Editor: S23-template-editor.html.

Manage mode

From Settings › Card templates. Built-in templates on top as tiles with a layout schematic; your templates below with the lists that use them. Tapping a template opens it in the editor (S23); built-ins open read-only and can be duplicated.

Manage mode: other states

No templates of your own yet, and loading.

Pick mode: the import finish step

The last import step (A-22): name the list, choose a card template and start sorting. The recommended template is preselected from the source and its fields; the preview is the first imported item on the real card. "Customize" opens the editor on a copy. When the duplicate step was skipped, the summary says "No duplicates found" (A-23).

Pick mode: states

Name validation, importing, a partial copy failure. Data was already read in the earlier steps, so this step works offline.

Change mode: a list's card template

From S09 › Card template or the S25 menu. The current template is marked; choosing another applies immediately with Undo (TPL-13). On a shared list the change applies to every member, and the screen says so.

iOS, web and large text

iOS: back chevron with the previous title, page sheets and an action sheet for template actions. Web: same layout as Android; on desktop the actions open as a menu next to the row. Large text: the preview becomes a button that opens it at full size and the carousel becomes a list.
