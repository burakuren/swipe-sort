S12 Pre-permission explainers and recovery

Shown before every system permission prompt (contacts, photos, notifications) and when access was denied. One layout for every permission: icon, title, what happens to the data, then the system prompt. Spec: S12-permissions.md. Shared import chrome (modal app bar, ImportStepper, bottom actions) matches S16–S21.

Contacts

Before the Android or iOS contacts prompt. “Continue” triggers the system prompt; when access is granted the import continues at S13. Denied access gets a recovery state with a working alternative.

Photos

Before gallery access. Photos skip field mapping and duplicate review, so the stepper has 3 steps (Choose source, Select items, Finish). Limited access (iOS, Android 14+) continues with the allowed photos.

Notifications

Push pre-permission for collaboration events (Android and iOS only). Shown once, right after a list is first shared or joined, and from Activity or Settings while permission is undecided. Not part of the import stepper.

iOS

iOS asks only once per permission: after a denial the only way back is Settings, so iOS recovery never offers “Allow access”. Contacts (iOS 18) and photos can be limited to a selection.

Accessibility

Large text: the explainer scrolls; the bottom actions stay pinned and wrap.
