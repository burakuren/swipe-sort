S14 File import (CSV and Excel)

Select items for the CSV or Excel source: pick a file, check the detected structure in a preview, choose Excel sheets, and recover from file errors. Spec: S14-file-import.md. Shared import chrome (modal app bar, ImportStepper, bottom actions) matches S16–S21.

Choose a file

The system file picker (out of scope) opens from “Choose file”. Reading starts as soon as a file is picked.

Preview

What SwipeSort detected: the header row, the separator and the rows that become items. The table scrolls sideways; mapping (S19) renames, hides and types the columns.

File errors

Each error says what happened and what to do, names the file, and offers a way forward. Error haptic on Android and iOS. The original file is never touched.

Web and iOS

Mobile web works like Android (the browser’s file chooser). Desktop adds a drop zone. iOS opens the Files picker from a page sheet.
