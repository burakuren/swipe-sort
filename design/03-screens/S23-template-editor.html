S23 Template editor

Choose which fields appear on cards and in what order: image area, title, subtitle, up to 6 field rows and up to 3 tags. Fonts and colors are fixed (TPL-04). The preview on top is the real card with the list's own items; previous and next cycle through them. Spec: S23-template-editor.md. Library: S22-template-library.html.

Editor

Flow 4: "Customize" in the import finish step opens a copy of the recommended template (Candidate) for the list Frontend hiring, Q4. The preview is pinned on top; the layout slots scroll below it in card order.

Live preview

Previous and next cycle through the list's items (wrapping at the ends). The preview shows exactly what the sort card will show: empty values are left out, long text wraps and truncates (TPL-05, TPL-06, TPL-07).

Editing the layout

Pickers open as bottom sheets. Rows reorder by dragging the handle or with the up and down buttons (accessible alternative).

Built-in and saved templates

Built-ins are read-only: duplicate first. A saved template opened from Settings or a list shows which lists use it; changes apply to all of them. Rename, Duplicate and Delete live in the overflow menu.

iOS, web and large text

iOS: Cancel and Save in the navigation bar, pickers as page sheets. Web desktop: drag with the mouse, keyboard reorder with Alt and the arrow keys. Large text: the preview opens from a button and row controls move below the field name.
