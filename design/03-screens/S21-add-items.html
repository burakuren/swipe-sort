S21 Add items to an existing list

From S09 “Add items”: the same import steps with list context. Columns are matched to the list’s existing fields, rows are checked against items already in the list (S20-existing), and new items join the current round. Sample: mert-family.csv added to Wedding guests (shared with Mert and Selin). Spec: S21-add-items.md.

Flow

Choose source (with list context) → select the file → match columns to the list’s fields → duplicates against existing items (S20-existing) → confirm → adding → back to the list with a snackbar.

Errors, offline and platforms

Partial add, offline (local sources work; Google Sheets needs a connection), web (contacts and gallery need the app; photos upload instead) and iOS.
