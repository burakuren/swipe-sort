The filter and sort sheet for a Results segment: field value chips with live counts, number ranges, many-value search, sort field and direction, Reset and "Show 12 items". Spec: S29-filter-sort.md. Opened from S28.

Filter and sort sheet

A bottom sheet over S28 for the segment on screen. Sort first (one choice), then filters by field values: AND across fields, OR within a field, the same vocabulary as S24. Chips show how many items each value would leave. "Show 12 items" applies; Reset clears everything back to Recently decided with no filters.

States, platforms and large text

Counts are computed on the phone from the working copy, so there is no loading or offline state for this sheet (lists over 5,000 items show "Counting…" in the button for up to a second). iOS uses a page sheet with Cancel and Reset in the bar; desktop web keeps the sheet inside the centered column.
