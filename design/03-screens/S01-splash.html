S01 Splash

Cold start only. Android uses the system splash screen (icon on the theme background, wordmark as the branding image); iOS uses a static launch screen; the web shows a brief loader only when loading takes longer than 300 ms. Spec: S01-splash.md.

Cold start

The splash stays only while the app opens its local database. Returning users go straight to Lists (S08); first launch goes to the introduction (S02); an invite link hands off to S32.

Opened from an invite link

App installed: the Android App Link or iOS Universal Link starts the app. The splash shows a status line while the invite is checked, then hands off to S32 (app) without showing onboarding first; onboarding is offered after joining.

iOS and web

iOS launch screens are static and carry no text (Apple HIG): the mark alone on the theme background. The in-app continuation (slow start, invite) is identical to Android. The web shows the mark with a thin loading bar only when the app takes more than 300 ms to load.
