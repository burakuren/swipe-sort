S04 Forgot password

From S03 "Forgot password?". Request a reset link, then set a new password from the email link (in the app when installed, otherwise on the web). The "sent" message never reveals whether an account exists. Spec: S04-forgot-password.md.

Request a reset link

The email field is prefilled from the sign-in form. Validation happens on submit; the button shows progress while sending.

Link sent

Same message whether or not the address has an account (no account enumeration). "Send again" unlocks after 60 seconds. "Open email app" opens the default mail app (Android intent, iOS mail URL); the prototype jumps to the new-password step.

Set a new password

Opened from the email link: in the app when installed (App Link / Universal Link), otherwise in the browser. Same password rules as sign-up.

iOS, web and large text

iOS: back chevron to Sign in; the new-password screen opens as a modal with Cancel. Web: the same steps in the phone column; after a reset on desktop the person can continue in the browser or on their phone.
