S16 Plain-text import

Step 2 of a plain-text import: paste a list or open a .txt file, one item per line. Parsed lines become items with one field, named in S19. Spec: S16-plain-text.md.

Paste or open a file

One item per line. The live count updates as the user types; blank lines are skipped and counted separately. Opening a .txt file loads its text into the same box, where it stays editable.

Loading and errors

Reading a file is usually instant; the spinner shows for large files. File errors say what happened and how to fix it; the paste box stays available as a fallback.

Accessibility

At 200% text the box keeps at least 6 visible lines and the page scrolls; the count and the file button stay below the box.

iOS and web

iOS: 44 pt bar with a back chevron to the source picker (edge swipe goes back) and close at the right; “Open a .txt file” opens the Files app. Web: the file opens with the browser’s file picker; on desktop the user can also drop a file on the page.
